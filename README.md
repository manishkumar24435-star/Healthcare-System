# 🏥 Healthcare Management System

A C++-based Healthcare Management System designed to organize and simplify hospital operations, including patient records, doctor information, appointments, room management, medicines, and billing.

## 📌 Project Overview

The Healthcare Management System is an academic software project that aims to improve the organization of hospital information and reduce manual record management.

The system is designed to provide structured management of healthcare-related records through a modular architecture using C++ and Object-Oriented Programming.

## 🎯 Objectives

* Manage patient information efficiently.
* Organize doctor records.
* Maintain appointment information.
* Manage hospital rooms and admissions.
* Organize medicine and pharmacy records.
* Support basic billing operations.
* Demonstrate Object-Oriented Programming and Data Structures.

## ✨ Key Features

* **Patient Management:** Store, search, and update patient records.
* **Doctor Management:** Organize doctor details.
* **Appointment Management:** Maintain appointment information.
* **Admission Management:** Manage patient admission and discharge records.
* **Room Management:** Organize room-related information.
* **Pharmacy Management:** Maintain medicine records.
* **Billing Management:** Support basic billing operations.
* **Record Management:** Organize information using suitable data structures.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/manishkumar24435-star/Healthcare-System.git
```

### 2. Navigate to the Project Directory

```bash
cd Healthcare-System
```

### 3. Build the Project

If the project uses CMake, run:

```bash
cmake -S . -B build
cmake --build build
```

### 4. Run the Application

The exact command depends on the executable generated by the build process.

For example, on Windows:

```bash
./build/Healthcare-System.exe
```

Adjust the executable path if your CMake configuration generates it elsewhere.
